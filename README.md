# jam-qa-mono

QA fixture for Jam (fictional brand "Brindle"). npm-workspaces monorepo; the site is `apps/web`
(Next.js 15 app router, `(marketing)` route group, posts in `apps/web/content/posts/`), static export
deployed to GitHub Pages on push to the default branch `trunk`.
Live: https://wespreadjam.github.io/jam-qa-mono/
